# Installation

Use the canonical, versioned guides instead of copying commands from this
mirror:

- [Getting started](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/GETTING_STARTED.md) — install and verify the CLI.
- [Installation channels](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/INSTALLATION.md) — native V binary, package
  managers, launcher options, and platform support.
- [Desktop installation](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/desktop/README.md#start-using-desktop) — standalone
  Electron app with its bundled backend.
- [Uninstall](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/UNINSTALL.md) — remove files safely.

Desktop does not require a separate CLI installation or source checkout. The
CLI remains available for automation and headless use.

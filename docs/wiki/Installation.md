# Installation

Use the canonical, versioned guides instead of copying commands from this
mirror:

- [Getting started](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/GETTING_STARTED.md) — install and verify the CLI.
- [Installation channels](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/INSTALLATION.md) — native V binary, package
  managers, launcher options, and platform support.
- [Veasel Code](https://github.com/veasel-labs/veasel) — the supported coding
  application with terminal and Desktop experiences.
- [Former Desktop migration map](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/LEGACY_DESKTOP_MIGRATION.md)
  — preserved capabilities, user data boundaries, and removal gates for the
  retired Agent Toolkit Electron app.
- [Uninstall](https://github.com/ulises-jeremias/agent-toolkit/blob/main/docs/UNINSTALL.md) — remove files safely.

Agent Toolkit is the portable capability layer: skills, agents, context,
MCP templates, workflows, and CLI tooling. Its former Electron Desktop is no
longer a supported product. Use Veasel Code for coding sessions; shared
Desktop/TUI session acceptance is tracked in
[Veasel #550](https://github.com/veasel-labs/veasel/issues/550).

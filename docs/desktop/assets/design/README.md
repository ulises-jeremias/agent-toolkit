# Desktop design references

Status: **HISTORICAL PROVENANCE** — updated 2026-09-30 for the Cozy Pixel
World reset ([ADR-035](../../../adrs/ADR-035-cozy-pixel-world.md)).

Every image in this folder is a **historical reference from the deprecated
Paper Co. concept phase**. None of these boards is visual authority anymore.
The current visual contract is [../../DESIGN.md](../../DESIGN.md) (Cozy Pixel
World); the current executable art lives in
`apps/desktop/public/world/` and is generated by
`apps/desktop/scripts/gen-world-assets.mjs` (original, license-clean art
wired through semantic theme keys in
[`apps/desktop/src/features/world/theme/`](../../../apps/desktop/src/features/world/theme/)).

## What remains true here

- Fictional metrics, statuses, navigation labels ("Market", "Guild Hall",
  fake agent counts) were never product truth and remain non-authoritative.
- Do not copy copyrighted game or third-party product assets when
  implementing. Production pixel art must be original or appropriately
  licensed (DESIGN.md §7).

# Desktop design references

This directory no longer stores concept boards. The boards from earlier
directions were removed from the active product tree on 2026-10-05; Git history
preserves their provenance. They included fictional interface states and
visual systems that no longer describe the shipping application.

Use [DESIGN.md](../../DESIGN.md) and [SEMANTIC_WORLD.md](../../SEMANTIC_WORLD.md)
for the current visual and interaction contracts. Review current, real Electron
captures in [`../electron/`](../electron/) and the README gallery. Production
pixel art is original and generated from the source in
`apps/desktop/scripts/gen-world-assets.mjs`; never copy third-party game art.

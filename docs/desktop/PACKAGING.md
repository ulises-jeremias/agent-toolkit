# Former Agent Toolkit Desktop packaging

> **Archive notice (2026-11-25):** Packaging details below apply to the former
> Electron product and historical releases only. They are not a supported
> installation path for Agent Toolkit or Veasel Code. Historical release assets
> remain immutable. See the [migration map](../LEGACY_DESKTOP_MIGRATION.md).

This page is retained as a historical pointer only. The Electron application
in `apps/desktop/` is retired from active product development, and current
Agent Toolkit releases are for the portable CLI and capabilities. Do not use
old build commands or release names here as current installation instructions.

Use [Veasel Code](https://github.com/veasel-labs/veasel) for the supported
coding application and see the
[migration map](../LEGACY_DESKTOP_MIGRATION.md) before handling old Desktop
data, workflows, or source assets. Historical releases and user data remain
untouched. The former packaging implementation can be recovered from Git
history while the migration gates are completed.

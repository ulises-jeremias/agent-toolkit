# User Story (WHAT)

Use for user-centered requirements that need business value, technical notes, and acceptance criteria.

## Default guardrails

1. Apply **`output-handshake`** before final output.
2. Use **`planning`** when estimation or splitting is needed.
3. Use **`task`** for purely technical work that is not a user story.

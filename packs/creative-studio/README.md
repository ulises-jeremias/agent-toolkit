# Creative Studio Pack

Advisory bundle for AI-native creative production (video, motion, image,
audio) across real applications — Kdenlive, Blender, GIMP/Krita/Inkscape,
OBS, REAPER and FFmpeg.

- **Install** via the `agent-toolkit-creative-studio` product
  (`distributions/products.yaml`); this pack file is docs-only per ADR-0003.
- **Architecture:** `docs/adrs/ADR-046-creative-studio-ecosystem.md`
- **Upstream evidence:** `docs/creative-studio/UPSTREAM_EVALUATION.md`
- **Compatibility:** `docs/creative-studio/COMPATIBILITY.md`

Creative capabilities are opt-in: enabling this pack's product never turns
on creative MCP servers for unrelated coding sessions.

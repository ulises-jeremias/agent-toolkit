# Empty-project sign prompt

Create one original pixel-art sign for an enchanted cozy developer-workspace
valley: a carved timber project-directory board on two posts, viewed from a
game-ready slightly top-down angle. Use transparent background, warm wood, a
soft mint-green plus rune, a few abstract pinned project tokens, subtle leaves
and flowers, crisp dark pixel outline, top-left light, hard pixel shadow,
limited palette, and a silhouette readable at 2× zoom. It must invite a user
to add a project, without text or interface. No chart, screen, generic
billboard, background, logo, UI, blur, gradients, or copied game design.

The generated sign was point-sampled to 64×50 source pixels. It is shown only
for the real empty-project directory state and its semantic hitbox opens the
project linking workflow.

# Website artwork

`valley-journey.webp` is original concept artwork generated for the Agent
Toolkit website on 2026-10-11. It establishes atmosphere only; it does not
depict live application state or a literal shipped workspace. The homepage
labels it as an illustration and uses separately captioned Desktop captures
for product evidence.

The artwork was generated from a prompt written for this project and does not
reuse supplied game assets, maps, characters, or interfaces. The lossless
source image remains in the local Codex generated-image archive; this WebP is
the optimized website copy.
